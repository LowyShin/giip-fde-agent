## 원인 (호스트 실측으로 확정)

1. **운영 하자**: `Test-GissueCjkContamination`(러너 잡 스코프)가 `git ... 2>&1` 두 곳
   (diff, diff --name-only)을 호출한다. 호출자(러너 본체)가 전역 `$ErrorActionPreference='Stop'`
   인 PS 5.1 환경에서는 git 의 무해한 stderr 경고(LF→CRLF 경고 등)가 NativeCommandError 종료
   오류가 된다 — 첫 번째 diff 는 함수의 `catch { return }` 에 걸려 게이트가 조용히 무동작이 되고,
   두 번째 diff 는 가드가 없어 함수 밖으로 throw 할 수 있다. 즉 Windows 호스트에서 CJK-QA
   게이트가 통째로 동작하지 않을 수 있는 상태였다.
2. **테스트 결함(지시 항목)**: `$j = Judge-Call` 뒤 `$j.Count` 검사 패턴은 함수 반환 1개짜리
   배열이 대입 시 스칼라로 풀리고 PSCustomObject 에 .Count 가 없어 PS 5.1 에서 깨진다.
   단, **정본의 `tests/test-gair-judges.ps1` 에는 이 패턴이 없다** — 정본 테스트는 소스 배선
   점검 + 순수 함수 검증 방식이고, 해당 패턴은 이식본(호스트 실행본) 테스트에만 있다.
   그래서 정본에서는 수정 B 를 적용할 지점이 없으며, 대신 수정 A 의 회귀 가드 점검(B8)을
   정본 테스트에 추가했다.
