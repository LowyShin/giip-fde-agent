### 문제 (43~50차가 반복해서 겪은 것)

43~50차 정비 세션이 **매 회차 상대링크를 스캔**했다. 그런데 스캐너를 **매 회차 새로 짰고**
스캐너마다 세는 대상이 달랐다 → "미존재 링크 N건" 기준선이 43차 28 → 44차 27 → 45차 26 → 46차 11 →
47차 31 → 48차 33 → 49차 26 → 50차 34로 출렁였다. 그래서 **45·46·47·48·49·50차 기록마다**
"N건 = 스캐폴딩 A + 코드예시 B 로 분해해야 하며, 스캐너마다 개수가 다르므로 **개수가 아니라
분류로 판정할 것**" 이라는 문장을 다시 써야 했다 — 같은 분류를 매 회차마다 다시 증명하고 있었다.

50차는 다른 회차와 달리 **실제 결함 1건**(49차 산출물의 깨진 링크)을 찾아 교정했는데,
