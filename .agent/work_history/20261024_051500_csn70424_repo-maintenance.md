## 미해결/후속

- **CI 러너 실환경 미확인** — GitHub windows-latest 러너에서의 실제 실행은 **아직 확인하지
  못했다**(PR 이 올라가야 실행된다). 로컬(DP01, Windows PowerShell 5.1)에서 cp437·cp65001 양쪽
  exit 0 을 실측한 것까지가 이번 세션의 확인 범위다. 러너의 코드페이지·node 설치 위치가 다르면
  CI 가 빨갛게 뜰 수 있으므로 **PR 을 올린 뒤 CI 결과를 반드시 확인해야 한다.**
- **`.github/workflows/` 경로 변경은 GitHub 토큰 `workflow` scope 를 요구할 수 있다** — push 를
  시도하면 이 권한 문제로 막힐 수 있다. 이번 세션은 push 하지 않았다(세션 소관).
- **기대 건수 하한선(20/4)** 은 테스트 추가·제거 때 수동 갱신해야 한다. 테스트를 의도적으로
  제거하면 이 값을 같이 낮춰야 한다(그렇지 않으면 CI 가 영구 red).
- **PR 이 빨간 게이트로 뜨는지 확인은 세션 소관** — "워크트리 green" 과 "PR green" 은 다르다
  (KNOW-005 교훈). 이번 세션은 워크트리 검증까지만 했다.
- **rule 53 §3 과의 정합**: 서버사이드 CI(정식 enforcement)와 클라이언트사이드 스크립트(보조)를
  **둘 다 유지**했다 — 어느 하나도 폐기하지 않았다.
