2. **[H] 창 건수는 회차마다 갱신**된다 — 이번 2h 4건·24h 13건. 2h 창은 173차 대비 4300 의 워치독 SKIP 노트 1건이 추가됐다. 고정값 아님, 매 회차 실측(워치독 SKIP 은 매 회차 2h 창을 바꾸므로 "전건 불변"으로 복사하지 말 것 — 173차 교훈).

4. **검수+보완 폴백 세션의 북킹 이슈 번호(giip 1503 등)는 작업 CSN 교차(404 권한 게이트)** — 그 번호에 쓰지 않는다(rule 76).
