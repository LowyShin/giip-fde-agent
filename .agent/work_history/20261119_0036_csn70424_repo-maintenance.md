1. **[H] 창 건수는 회차마다 갱신** — 이번 2h **4건**(178차 3건 + 4300 진입)·24h 13건(178차와 동일 집합이나 매 회차 재계산한 결과다). 고정값 복사 금지, 집합뿐 아니라 이슈별 마지막 코멘트 시각까지 대조(161차 교훈).
2. **워치독 쿨다운 스킵은 시간이 지나면 2h→24h→창 밖으로 자연 이탈·재진입** — 이번처럼 2h 창이 3→4 로 더 찰 수 있다. "2h 비었으니 조회 실패"로 오판 금지.
3. **[G] 게이트 유형(4530·2648·4211·1968·4130)은 본문/코멘트에 Test Procedure 섹션이 없는 한 계속 REVIEW 유지** — 본문이 바뀌어 섹션이 추가되면 그때 [G] 가 Actionflow 재검증 대상으로 승격한다. 마지막 코멘트가 바뀌면(불변 깨지면) 다음 회차는 본문+코멘트를 직접 재파싱할 것(코멘트 서술 신뢰 금지).
4. **5664 는 NEEDS_DECISION, 5667 은 DONE 으로 안착** — audit 전이 확정 상태. 추가 사람 코멘트가 붙으면 그때 재검증.
5. **검수+보완 폴백 세션의 북킹 이슈 번호(giip 1503 등)는 작업 CSN 교차 가능성** — 그 번호에 직접 쓰지 않는다(rule 76). giip 1503 은 CSN 70424 로 조회 시 교차 404(권한 게이트)라 미기재.
