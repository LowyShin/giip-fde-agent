### 1-3. upstream 없는 브랜치에서 러너가 **기동 자체를 죽인다** (신규 발견)

- **재현**: 같은 체크아웃에서 `Invoke-GissueSelfPullNotOnMainCheck` 를 부르면

  At scripts/gissue/run-gissue-claude.ps1:1827 char:17
  + ... $upstream = & git -C $RepoRoot rev-parse --abbrev-ref '@{upstream}' 2 ...
      + FullyQualifiedErrorId : NativeCommandError

- **원인**: `Test-GissueUpstreamGone` 가 `2>$null` 로 stderr 를 숨겼지만, Windows PowerShell 5.1 은
  native 명령의 stderr 를 **ErrorRecord(NativeCommandError)로 올리고** 이 러너의 기본값

  스케줄러가 뜨면 **아무 작업도 못 하고 죽는다**.
- **조치**: git 호출 구간만 `$ErrorActionPreference = 'Continue'` 로 임시 낮추고 종료 코드로 판정.
