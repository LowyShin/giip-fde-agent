## 변경 내용

### 신규 `scripts/gissue/lib/bounded-process.ps1`

- `Invoke-GissueBoundedProcess -FilePath -ArgumentList -TimeoutSec [-WorkingDirectory]`
  → `@{ Started; TimedOut; ExitCode; StdOut; StdErr }`.
  Start-Process + `WaitForExit(유한 대기)` + 한도 초과 시 Kill. stdout/stderr는
  임시 파일 경유(파이프 버퍼 교착 없음), UTF-8로 읽는다. 임시 파일은 finally에서 삭제.
  PS 5.1 호환(잡·스레드 미사용). 인자는 공백·따옴표 포함 시 큰따옴표로 감싸 1개 인자로
  전달한다(PS 5.1 Start-Process -ArgumentList는 자동 따옴표 처리를 안 한다).
- `Resolve-GissueBoundedCallTimeoutSec -Kind Gh|Git` — Gh 기본 60초
  (env `GISSUE_GH_CALL_TIMEOUT_SEC`), Git 기본 30초
  (env `GISSUE_GIT_CALL_TIMEOUT_SEC`). 양의 정수가 아니면 기본값.
  근거: 실측 건강 상태 gh 6초·git 2초 이내, 한도 소진 실패는 즉시 반환.

### `scripts/gissue/worktree-safety.ps1` — 래퍼 + 전 호출처

- `Invoke-GissueExternalCall -FilePath -ArgumentList [-TimeoutSec] [-Kind Gh|Git]`:
  헬퍼가 로드돼 있으면 그걸 쓰고, 없으면(부분 체크아웃) 기존 직접 호출(`&`)로
  떨어진다. 한도는 -Kind로 정하고 명시 -TimeoutSec이 우선한다.
- 묶은 호출처(전부 fail-closed — 타임아웃은 실패로 취급, 삭제 금지):
  - `Get-GissueMergedBranchSet`: `git remote get-url origin` + gh `pr list`
    (타임아웃 시 "시간 초과" WARN 로그, Ok=$false, 전 항목 MANUAL-REVIEW).
  - `Get-GissueWorktreeEntries`: `git worktree list` (+선택 -Log 파라미터 —
    타임아웃 시 빈 목록 반환, 이번 실행은 이 레포를 건너뛴다).
  - `Get-GissueRepoIntegritySnapshot`: `rev-parse HEAD` / `remote get-url`
    (타임아웃 시 빈 값 = 판정 불가, 종전 실패와 동일).
  - `Test-GissueGitObjectIsCommit`: `cat-file -t` (타임아웃 시 $false).
  - `Test-GissueJunctionTargetHealthy`: `rev-parse` / `remote get-url`
    (타임아웃 시 Ok=$false, 사유에 "시간 초과" 명시).
  - `Test-GissueWorktreeContentInMain`: `rev-parse` / `--verify` / `merge-base`
    (타임아웃 시 Determined=$false).
  - `Get-GissueWorktreeDirtyPaths`: `git status -uall` + `TimedOut` 필드 추가.
    호출자는 타임아웃 시 MANUAL-REVIEW로 보류한다.
  - 정리 엔진 본문: `worktree prune`(타임아웃 시 prune 없이 계속),
    비-Claude dirty 확인용 `status --porcelain`(타임아웃 시 비고만 생략 — 참고용 메모라
    삭제 판정에 쓰이지 않는다), `worktree remove [--force]`(타임아웃 시
    MANUAL-REVIEW, `--force` 재시도 없음 — 멈춘 삭제의 상태를 알 수 없는데 강제하면
    무엇이 지워졌는지 모른다), `branch -D`(best-effort, 종전 동일),
    `ls-remote`/`push --delete`(타임아웃 시 건너뛰거나 경고만).

- `Invoke-GissueWorktreeCleanup` 래퍼(run-gissue-claude.ps1) 변경 없음 —
  호출이 빨리 돌아오면 항목 경계 한도 검사가 설계대로 동작한다.
