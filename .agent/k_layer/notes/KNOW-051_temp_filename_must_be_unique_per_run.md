# KNOW-051 — 임시 파일 이름은 실행마다 고유해야 한다: 고정명은 동시 실행 게이트를 거짓 FAIL 로 만든다

> 근거: 2026-11-16 CSN 70424 저장소 정비 145차 세션 실측 (work_history 20261116_1007) · 발행: 2026-11-16 · 상태: 검증됨(수정 전·후 동시 실행 대조)

> 관련 파일: `scripts/gissue/tests/test-verify-runner-korean-encoding.ps1` · `scripts/gissue/tests/test-temp-filename-collision.ps1` · `scripts/gissue/run-repo-gates.ps1`

## 요지

**임시 파일 이름이 고정**되어 있으면, 같은 호스트에서 **동시에 실행되는 다른 프로세스**가 그 파일을
덮어쓰거나 지울 수 있다. 게이트/테스트가 자기 출력 리다이렉트를 고정 경로에 쓰면, 동시 실행 중
상대 프로세스가 파일을 지운 순간 **출력이 사라져 "검증 실패"** 로 오인된다.

145차는 공유 체크아웃과 워크트리에서 **같은 커밋** 의 게이트가 한쪽 FAIL / 한쪽 PASS 였는데,
원인은 코드가 아니라 **동시 실행**이었다. 이 호스트는 CSN 별 정비 세션이 매시 동시에 돌아가므로
(레포가 달라도 임시 폴더는 하나) 충돌은 예외가 아니라 **일상**이다.

## 규칙

1. **임시 파일·디렉터리 이름은 실행마다 고유하게 만든다** — `$PID` · GUID 등. 고정 금지.
   `Start-Process -RedirectStandardOutput` · `Out-File` · `Set-Content` ·
   `Remove-Item` 대상 **모두** 같은 규칙(생성과 삭제가 같은 이름이어야 한다).
2. **테스트가 자기 산출물을 지우면 동시 실행 상대가 죽는다.** 삭제 지점도 고유 이름이어야 한다.
3. **거짓 FAIL 은 "검증 실패" 로 오인된다.** 게이트 FAIL 을 곧바로 코드 결함으로 단정하지 말고
   "같은 커밋을 다른 위치에서 다시 돌렸나 / 동시에 돌렸나" 를 먼저 확인한다.
4. **회귀 테스트는 수정 전 코드에 FAIL 하는 것을 증명한다.** 수정 후 PASS 만 남기면
   검사기 자체가 고장나도 조용히 통과한다.

## 적용

- 새 회귀 테스트를 추가하면 게이트 기대값(`$ExpectedPs1TestCount`)도 함께 올린다 — 빠지면
  "테스트가 사라져도 통과" 하는 방어 공백이 생긴다(145차 42 → 43).
- **스캔 범위도 함께 고정한다.** 저장소 루트는 경로 단계 수로 계산하지 말고 `.git` 을 만날 때까지
  올라가 찾는다(145차 실측: `Split-Path -Parent` 2회면 `scripts/` 에서 멈춰 **102건 중 92건만** 훑었다).
  스캔 도구 자체가 자기 범위를 증명하는 단언(디렉터리별 건수)을 포함해야 한다.
